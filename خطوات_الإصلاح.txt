   خطوة واحدة تحل المشكلة نهائياً
═══════════════════════════════════════════════════

  الخطأ: null value in column "name"

  السبب: دوال الخادم في Supabase ما زالت
         النسخة القديمة. الملف المُصحَّح لم
         يُنفَّذ بعد، أو نُفِّذ جزئياً.


  ══════ الحل ══════

  ١) افتح موقع Supabase وسجّل دخولك

  ٢) من القائمة اليسرى اختر:  SQL Editor

  ٣) اضغط:  + New query

  ٤) افتح ملف  admin_rpc.sql  بالمفكرة
     (موجود في مجلد cloud داخل النظام)

  ٥) حدّد كل المحتوى:  Ctrl + A
     انسخه:            Ctrl + C

  ٦) الصقه في نافذة SQL Editor:  Ctrl + V

     ⚠ تأكد أنك لصقت الملف كاملاً
       من أول سطر إلى آخر سطر

  ٧) اضغط الزر الأخضر:  RUN

  ٨) انتظر ظهور:  Success


  ══════ التأكد ══════

  ارجع للنظام واضغط:  فحص الإعدادات

  يجب أن ترى:

     ✔ رابط السحابة
     ✔ المفتاح العام
     ✔ الاتصال بالخادم
     ✔ دوال الإدارة على الخادم
     ✔ إصدار الدوال: 1.2.1 (المطلوب 1.2.1)

  إن ظهر ✘ أمام «إصدار الدوال» فالملف لم
  يُنفَّذ كاملاً — أعد الخطوات من جديد.


  ══════ ثم ══════

  ضع علامة على: حساب مدير عام
  اكتب اسم مستخدم وكلمة مرور
  اضغط: إنشاء الحساب

  ستنجح هذه المرة.
