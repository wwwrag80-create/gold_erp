        نظام جاديت — البدء في 4 خطوات
═══════════════════════════════════════════════════

  ⚠ خطوة إجبارية أولى (مرة واحدة فقط)
  ────────────────────────────────────
  افتح Supabase > SQL Editor > New query
  الصق محتوى الملف:   cloud/admin_rpc.sql
  اضغط RUN

  بدون هذه الخطوة لن تُنشأ أي حسابات.


  ١) شغّل النظام
  ───────────────
     انقر:  START.bat
     ادخل:  admin / admin


  ٢) أنشئ حساب المدير العام
  ──────────────────────────
     الإدارة العليا > النظام السحابي > حسابات المصانع

     ضع علامة على:  حساب مدير عام
     اكتب اسم مستخدم وكلمة مرور من اختيارك
     اضغط: إنشاء الحساب

     ثم أغلق النظام وادخل بحسابك الجديد.


  ٣) أنشئ حسابات المصانع
  ───────────────────────
     نفس الشاشة، بلا علامة «حساب مدير عام»
     اكتب: اسم المصنع + مستخدم + كلمة مرور


  ٤) اصنع الملف التنفيذي
  ───────────────────────
     انقر:  MAKE_EXE.bat
     ستجد: dist\gold_erp.exe

     أرسل الملف لأي مصنع مع حسابه.
     ونفس الملف تستعمله أنت بحسابك كمدير.


═══════════════════════════════════════════════════
  لماذا لم يعد يطلب مفتاح service_role؟
═══════════════════════════════════════════════════

  لأن إدارة الحسابات صارت تتم عبر دوال على الخادم
  تتحقق من هويتك بنفسها. فالملف التنفيذي لا يحمل
  أي مفتاح خطير، ولا يستطيع أي عميل إنشاء حسابات
  أو حذفها مهما فعل بالملف.
