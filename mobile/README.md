# جاديت للجوال (أندرويد)

نسخةٌ للجوال من دورة التعامل مع المحلات: المحلات، فاتورة بيع ومرتجع،
سندات قبض وصرف (ذهب بعياره ونقد)، كشف الحساب والأرصدة، حركة رقم التشغيل،
المعلّقات، مشاركة المستند صورةً أو PDF، والنسخ الاحتياطي.

البيانات في الجوال وحده (IndexedDB داخل التطبيق) — لا سحابة ولا اتصال.

## الفرق المقصود عن برنامج الكمبيوتر

- لا «وارد من التصنيع» ولا مخزون: رقم التشغيل يُباع ولو لم يُسجَّل قبلها،
  وتُكتب أوزانه في سطر الفاتورة.
- رقمٌ رجع بمرتجعٍ سابق تُعبَّأ أوزانه وأجره من ذلك المرتجع تلقائياً،
  والمرتجع يُعبَّأ من فاتورة البيع.

## المعادلات

`web/js/gold.js` منقولةٌ من `services/gold_math.py` و`services/karat_view.py`
بترتيب العمليات نفسه، و`web/js/num.js` يقرّب كما تقرّب بايثون حرفياً.
الفحص يقارن الاثنين على أكثر من مئة ألف حالة:

    python mobile/tests/parity_gen.py > /tmp/cases.json
    node mobile/tests/parity.js /tmp/cases.json
    node mobile/tests/domain.test.js
    node mobile/tests/e2e.js [مجلد_للصور]     # يحتاج playwright

## البناء والتوقيع

1. `.github/workflows/android.yml` يبني على GitHub ملفاً **غير موقّع**
   وينشره في الإصدار `mobile-unsigned`.
2. يُوقَّع خارج المستودع بمفتاح المالك:

       python mobile/tools/sign_apk.py --key DIR in.apk out.apk

   المفتاح (`DIR/key.pem` و`DIR/cert.der`) لا يدخل المستودع أبداً. والمفتاح
   نفسه في كل تحديث شرطٌ لتثبيت النسخة الجديدة فوق القديمة دون حذف بياناتها.

رقم الإصدار في `web/version.json` (يقرؤه البناء والتطبيق).

## التحديث (بلا سحابة المالك)

- الملف الموقّع يُضاف إلى `mobile/dist/jadeite-mobile-<الإصدار>.apk` ويُسجَّل في
  `mobile/dist/versions.json` (`version`, `code`, `file`, `sha256`, `notes`).
  يُنزَّل من `raw.githubusercontent.com` — من GitHub لا من سحابة المالك.
- **القناة**: الصفحة (issue) رقم 23 في المستودع. في نصّها بعد
  `<!-- jadeite-mobile-channel -->` كتلة JSON بآخر إصدارٍ منشور (الرقم والبصمة
  والرابط). لا تُغلق ولا تُعدَّل يدوياً.
- **الناشر**: يثبّت الإصدار الجديد على جواله، ثم «التحديثات ← إرسال … للجميع».
  التطبيق يتحقّق أولاً أن ملف GitHub هو المثبّت عنده نفسه (الرقم والبصمة ومفتاح
  التوقيع)، ثم يكتب القناة بمفتاح GitHub شخصي (Issues: Read and write على
  هذا المستودع وحده) محفوظٍ في الجوال خارج النسخ الاحتياطية.
- **المستخدمون**: يقرأ التطبيق القناة عند فتحه وكل 6 ساعات في الخلفية (والجهاز
  متصل)؛ فإن وجد أحدث نزّله، وتحقّق من بصمته، ونبّه بإشعار. التثبيت بلمسة
  (أندرويد لا يثبّت وحده)، والبيانات تبقى لأن المفتاح واحد.

## بقاء البيانات بعد حذف التطبيق

- **الحفظ التلقائي في مجلد** يختاره صاحب الجهاز (يفتح على Documents): بعد كل
  عملية يُكتب `jadeite-data.json` ونسخة اليوم `jadeite-data-YYYY-MM-DD.json`
  (تبقى آخر 14). بعد إعادة التثبيت تعرض شاشة الترحيب «عندي بيانات سابقة»
  فيُختار المجلد نفسه ويُسترجع كل شيء.
- **نسخ Google الاحتياطي** لأندرويد مفعّل أيضاً (يستثني مفتاح النشر وملفات
  التحديث المنزّلة).
