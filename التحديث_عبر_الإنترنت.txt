   التحديث عبر الإنترنت — خطوة بخطوة
═══════════════════════════════════════════════════

  ملاحظة مهمة: ملف .env عندك يحتوي بالفعل على
  SUPABASE_URL و SUPABASE_SERVICE_KEY — فلا تحتاج
  ضبط أي شيء يدوياً. الأدوات تقرأ منه تلقائياً.


  ══════════════════════════════════════════════
  الخطوة ١ — أنشئ مساحة التخزين (مرة واحدة فقط)
  ══════════════════════════════════════════════

  ١. افتح  supabase.com  وسجّل الدخول
  ٢. اختر مشروعك
  ٣. من القائمة اليسرى:  Storage
  ٤. اضغط:  New bucket
  ٥. الاسم بالضبط (انسخه كما هو):

         app-updates

  ٦. فعّل الخيار:  Public bucket   ✔
  ٧. اضغط:  Create bucket

  ⚠ الاسم يجب أن يكون بالحروف الصغيرة وبالشرطة
    تماماً: app-updates

  لماذا عامّة؟ لأن العملاء يقرؤون منها بلا تسجيل
  دخول. لا تحمل بيانات — الكود فقط.


  ══════════════════════════════════════════════
  الخطوة ٢ — انشر التحديث
  ══════════════════════════════════════════════

  في جهازك أنت، افتح موجّه الأوامر داخل مجلد
  gold_erp (اكتب  cmd  في شريط عنوان المجلد)، ثم:

      python tools/publish_update.py

  سترى:

      بناء الحزمة…
        الإصدار 4.4.0 · 145 ملف · 1.38 ميجابايت
      رفع الحزمة…
        ✔ jadeite_update_4.4.0.jup
      نشر البيان…
        ✔ latest.json
      ════════════════════════════════════
        تم النشر — كل عميل سيرى الإشعار

  انتهى. لا خطوات أخرى.


  ══════════════════════════════════════════════
  الخطوة ٣ — ما يحدث عند العميل تلقائياً
  ══════════════════════════════════════════════

  ١. يفتح العميل النظام كالمعتاد
  ٢. بعد ٨ ثوانٍ يجري فحص صامت في الخلفية
  ٣. إن وُجد تحديث يتحوّل الزر أعلى الشاشة إلى:

         ⬆ تحديث متاح 4.4.0      (ذهبي لامع)

  ٤. ينقر عليه فيرى نافذة فيها:
       • الإصدار الجديد والمثبَّت
       • تاريخ النشر والحجم
       • قائمة التغييرات كاملة
  ٥. يضغط «نعم» فيبدأ التحميل بشريط تقدّم
  ٦. يُثبَّت تلقائياً بعد التحقق من البصمة
  ٧. رسالة: «أعد تشغيل النظام لتفعيل التحديث»

  ⚠ العميل لا يحتاج أي إعداد إطلاقاً.


  ══════════════════════════════════════════════
  للتحديثات القادمة
  ══════════════════════════════════════════════

  في كل مرة أرسل لك نسخة جديدة:

  ١. فُكّ الملف واستبدل مجلد gold_erp عندك
  ٢. شغّل:   python tools/publish_update.py
  ٣. انتهى — كل العملاء يرون الإشعار

  (الخطوة ١ من هذا الدليل لا تُعاد أبداً)


  ══════════════════════════════════════════════
  إن ظهرت مشكلة
  ══════════════════════════════════════════════

  «مساحة التخزين app-updates غير موجودة»
     → لم تُنشئها أو الاسم مكتوب خطأً.
       راجع الخطوة ١.

  «SUPABASE_SERVICE_KEY غير موجود»
     → افتح .env وتأكد من وجود السطر:
       SUPABASE_SERVICE_KEY=<المفتاح>
       تجده في: Supabase ← Settings ← API
                ← service_role

  «python is not recognized»
     → بايثون غير مثبّت أو ليس في PATH.
       ثبّته من python.org مع تفعيل:
       [x] Add Python to PATH

  العميل لا يرى الإشعار
     → تأكد أن نسخته 4.4.0 فأحدث (النسخ الأقدم
       لا تحمل ميزة الفحص)، وأن جهازه متصل
       بالإنترنت. الفحص يجري بعد ٨ ثوانٍ من فتح
       النظام.


  ══════════════════════════════════════════════
  الأمان
  ══════════════════════════════════════════════

  ١. HTTPS إلزامي — رابط غير مشفّر يُرفض
  ٢. النطاق مُقيَّد بسحابتك وحدها
  ٣. بصمة SHA-256 تُطابَق بعد التحميل
  ٤. حدّ للحجم 300 ميجابايت
  ٥. نسخة احتياطية قبل التثبيت
  ٦. فحص بعد التثبيت — وإن فشل تُستعاد النسخة
     السابقة تلقائياً
  ٧. لا تثبيت تلقائي — بنقر العميل فقط
  ٨. البيانات لا تُمسّ: قواعد المصانع والإعدادات
     والصور والنسخ الاحتياطية
